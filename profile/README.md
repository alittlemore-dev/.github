## About

**alittlemore.dev** is a growing ecosystem of projects designed to turn curiosity into steady, meaningful progress. It brings useful tools, learning resources, and ideas together under one home.

The goal is to:

- create a unified portfolio for projects built with care;
- help software developers strengthen their skills through approachable tools and educational content;
- create a place where people with a shared curiosity and a desire to grow can find one another.

## What we're building

### Personal knowledge, made useful

A structured personal workspace that goes beyond free-form notes. It helps turn information into an organized, connected, and practical knowledge system for everyday life.

### Developer growth, made practical

Tools and content that help software developers understand their competencies, choose what to learn next, and build knowledge through consistent practice.

Every project is shaped by a shared design system so the ecosystem feels coherent, thoughtful, and easy to use.
